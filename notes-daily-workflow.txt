DeepSeek Harness 学习分支日常流程
=================================

分支结构
--------
- master          同步线，跟随官方 upstream，不直接改代码
- learning-notes  学习笔记分支，所有学习、探索、笔记、实验都在这里

远端
----
- origin    git@github.com:cgspwei/deepseek-harness.git  (个人 fork)
- upstream  git@github.com:deepseek-ai/deepseek-harness.git (官方)

日常同步（先同步 master，再让学习分支跟上）
------------------------------------------
    git checkout master
    git fetch upstream
    git merge --ff-only upstream/master
    git push origin master

    git checkout learning-notes
    git merge master

学习分支提交
------------
    git add <files>
    git commit -m "notes: ..."
    git push origin learning-notes

注意事项
--------
- master 只做同步，不要在上面直接改代码
- learning-notes 合回 master 时用 --no-ff merge 或 cherry-pick，别把临时代码带进主线
- 先 checkout 再操作，确认当前分支（git branch --show-current）
